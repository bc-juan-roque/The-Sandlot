# The Sandlot

Shareable, single-file interactive prototypes, published with GitHub Pages from the repo root.
Each prototype is self-contained in its own folder:

```
<project>/
  index.html   ← the published page  →  https://bc-juan-roque.github.io/The-Sandlot/<project>/
  src/         ← anything used to produce it (templates, styles, scripts, assets, build script)
```

| Prototype | Folder |
|---|---|
| Consolidated commerce.com navigation | `commerce-nav/` |

## Adding a prototype

1. Create `<project>/index.html` (keep it self-contained: inline CSS, JS, SVGs). Put working files in `<project>/src/`.
2. Add a card for it in the root `index.html`.
3. Commit and push. Pages redeploys in about a minute.

## commerce-nav

`commerce-nav/index.html` is generated. Edit the files in `commerce-nav/src/`, then run:

```
python3 commerce-nav/src/build.py
```

Open `commerce-nav/index.html` in a browser to review it (Host Grotesk loads from Google Fonts, so be online for the font).

| File in `src/` | What it is |
|---|---|
| `shell.template.html`, `css/shell.css`, `js/shell.js` | Review shell: address bar, version and variation switcher, review notes, live controls |
| `desktop.html` | Desktop prototype: Commerce bar, BigCommerce and Feedonomics Solution bars, every menu, wireframe page |
| `css/styles.css`, `js/nav.js` | Desktop styles (tokens from the Multi-Brand design system, BC mode) and behavior |
| `css/mobile.css`, `js/mobile.js` | Mobile styles and behavior. The mobile page is generated by `build.py` from the menus in `desktop.html`, so links and content match |
| `js/embed.js` | Lets the prototype pages talk to the shell |
| `assets/` | Commerce logo and the eight Feedonomics platform logos |
| `build.py` | Inlines everything into one `index.html` |

The gear at the bottom right opens a control panel for animation timing, hover-focus dimming and
placeholder content. "Copy changes" lists what you changed so it can be applied back to the source;
"Reset all" restores the defaults. Defaults live in the `CONTROLS` list in `js/shell.js`.

**Versions and variations.** The bottom-left toolbar has a Version dropdown, Variation buttons (hidden when a version has only one) and a Page switcher. Versions are defined in the `VERSIONS` object in `js/shell.js`; each holds numbered variations.

| Version | Variations | What it is |
|---|---|---|
| Desktop | 1–2 | Commerce bar plus a Solution bar for BigCommerce and Feedonomics. Var 1 = menus open and close on click. Var 2 = same, and once a menu is open, hovering another menu button switches to it with a slide and cross-fade |
| Mobile | 1–2 | Var 1 = push down: the Commerce menu expands under its bar and pushes the product bar down, one menu open at a time. Var 2 = floating: the Commerce menu is a card below the product bar, and opening it hides the product menu; the product menu can then expand above the card and push it down |

Deep links: `#desktop-1`, `#mobile-2`, and a page after the variation, for example
`#mobile-2/bigcommerce/pricing`. The address bar and URL follow the page you are on.

**Review mode.** The Review toggle lists the open questions for the current version and variation. They live in the `notes` arrays in `VERSIONS` (`js/shell.js`); add or remove entries there.

**Pages.** Every nav and sub-nav item has its own page, titled with the item's label. Routes are generated from the links in `desktop.html`, so adding a link gives it a page. Items that appear in more than one menu share a page.

**Behavior.**
- Menus open on click; Esc, clicking outside, or the dimmed page closes them.
- Desktop variation 2 only: once a menu is open, hovering another menu button (after a short hover intent) switches to it: the old menu slides out and fades, the new one slides in from the side you are heading. The gear has controls for the hover delay, slide distance and fade-out.
- The Commerce bar is sticky on Commerce pages. On BigCommerce and Feedonomics pages it scrolls away and the Solution bar stays pinned.
- Menu links go medium weight, nudge 4px right and show an arrow on hover. Hovering a menu item dims the others, then they fade back after a short pause.
- Cards (Surface, Integrations, the AI Labs strip) are one big link.
- On mobile, rows with a chevron drill into a panel with a Back row, and a scrim dims the page while any menu is open (tap it to close).

Motion timing and easing are variables at the top of `css/styles.css` and `css/mobile.css`; `prefers-reduced-motion` turns animation off.
